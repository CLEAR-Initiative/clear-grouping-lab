Layer key

What each grouping layer does, step by step, what it is compared against, and how it came out on the chosen day. Every layer groups the same signals, so the differences between two layers come down to the one thing that was changed. Back to the viewer.

What every layer has in common

  1. Take one country-day of signals (X posts, Dataminr, ACLED, …) and walk them once, in publication order. No decision is revisited, so a different order could group differently.
  2. For each signal, either join an event the layer has already built that day, or start a new event. Replayed layers start the day with no open events; only clear-as-run carries events from earlier days.
  3. Signals judged irrelevant are dropped and join nothing. The model-free layers reuse CLEAR's own verdict; the Jev layers ask Jev again, so they drop a few more.

The numbers below describe shape only: how much a layer merges, not whether the merges are right. Correctness comes from judgments (pair precision and recall in score.py). Single-signal share counts events built from one signal.
