Grouping lab

Judge how signals were grouped into events. Each card is one event as the chosen layer built it; every row is one original signal. Your judgments are about signals, so they score every layer at once. Nothing here is pre-judged by a model.

Should these be one event? Each card is an event the layer built from more than one signal. Read the rows; tick not this one on any signal that reports a different real-world occurrence, then press Yes, one event for the rest. Same occurrence means the same thing happening, not the same actor or the same kind of attack; use select and One campaign for those. Click a row's text to expand it.
Find the ones that belong together. Every event the layer built from a single signal, plus every signal it dropped (grey). Rows are grouped by state so reports of the same thing sit near each other; the location is CLEAR's resolved place and is often only the state or "Sudan", so go by the place names in the text. Tick select on two or more rows that report the same occurrence and press Same event in the bar at the bottom. You can also select a grouped card on tab 1 to add these signals to it.
Judgments save in this browser per day as you go. Download writes <date>.<judge>.json; move it to judgments/<country>/ and run python3 score.py --country … --date … --all.
